怎么玩

  1. 答对一题，得到一个知识点方块，点棋盘的某一列把它放下去。
  2. 两个相同的方块挨在一起（左右或上下）就合成下一级：数据 → 频数分布 → 均值 → 方差 → 标准差 → 概率 → 二项分布 → 正态分布 → 中心极限 → 区间估计 → 假设检验 → 回归分析。三个挨在一起直接连升两级，连锁合成分数更高。
  3. 答错一题，掉下一块「坏账」石头占格子。棋盘满了游戏结束。
  4. 答错的题过几题会再考你，答对就核销一块坏账。连对 5 题下一个方块升一级，连对 10 题再核销一块坏账。
  5. 等级越来越高时，太低级的小方块会自动「结转」清掉，给你腾地方。
  6. 按单局分数评段位：出纳 → 会计 → 审计师 → 财务经理 → CFO → 合伙人。还有 12 个成就徽章等你解锁。

🐍 贪吃蛇模式：先读题，再控制蛇去吃正确选项的字母。吃对蛇变长、加分，越吃越快；吃错或撞墙、撞到自己扣一颗心，三颗心用完结束。手机滑动屏幕或按方向键，电脑用方向键或 W/A/S/D，空格暂停。

电脑键盘：答题按 A/B/C/D 或 1-4；放方块按 1-5，或 ← → 移动、空格落下。
